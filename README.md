# PVT

Performance-oriented computing labs in C covering cache behavior, loop unrolling, DGEMV/DGEMM, and numerical experiments.

## Overview

This repository contains several practical assignments dedicated to performance analysis, optimization techniques, and numerical computation experiments.

## Structure

- `branch-image-dark` - branch behavior experiments
- `pipeline-loop-unrolling` - loop optimization tasks
- `cache-dgemm` - cache-aware matrix multiplication
- `pvt2`, `pvt3`, `pvt4`, `pvt5` - additional performance labs

## Stack

C, shell scripts, gnuplot, benchmarking artifacts.

## Notes

This repository is organized as a course archive for performance engineering labs.
